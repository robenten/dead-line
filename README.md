# DEAD LINE

A single-file arcade game — graveyard shift.

Pick a side: **HUMAN** or **ZOMBIE**. Steer with arrows / WASD or swipe on mobile.

## Play

Open [the GitHub Pages site](https://robenten.github.io/dead-line/) and play in your browser — no install, no build step.

Or scan on your phone:

<p align="center"><img src="snake-qr.png" alt="QR code to play DEAD LINE" width="250"></p>

## Files

- `index.html` — DEAD LINE (snake vs zombies)
- `snake.html` — classic snake

Both are fully self-contained HTML files (markup, CSS, and JS inline).
